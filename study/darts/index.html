Ⅱ-A 用具及び設備 — 数値の巣。最頻出

・ダーツ = ティップ・バレル・シャフト・フライトと認識でき(フライトシャフト一体型も可)、1本30cm以内 かつ 3本で75g以下。ティップは滑らかな針状のプラスティック製。
・公認マシン = フェニックスダーツジャパン株式会社製 PHOENIX シリーズ。1−20の時計型。中心の内側=インナーブル/外側=アウターブル/内側の狭い枠=トリプル枠/外側の狭い枠=ダブル枠。
・床からブルの中心まで 1730mm。
・"20"の枠は2色のうち濃い色でトップセンター。
・オッキ: 高さ10mm〜100mm以内、ボード中心→オッキ後端の対角線 2990mm(対角線の誤差 ±15mm)。
・認識できないダーツを投げた場合 = 警告1。審判は試合後コントロールに伝える。
⚠️ 引っかけ注意 — 旧規定(2017頃)ではマシン製造元が「株式会社エイチ・アイ・シー製」だった。2026年テキストは「フェニックスダーツジャパン株式会社製」。古いブログの丸暗記は失点する。±15mm も旧「いずれも」→ 現行は「対角線の長さ」のみ。

Ⅱ-B 投げ方 / 40秒ルール — 記述でも出る

・すべて片手で1本ずつ。一度に3本まで=1投(ワン・スロー)。2本以下で終了時は3本投げる必要なし。
・投げる必要のないダーツを投げた=注意1(1試合中に注意2度で警告1)。
・スローイングは対戦相手と交互。オッキの後端から。左右に出る場合は延長線上より後ろから。
・プレーエリアライン(台と台との境界線)は決して越えない。
・相手が抜き終わりスローイングラインの後方に戻ってくるまで構えに入らない(注意2度で警告1)。
・セットアップの体勢での素振り禁止。セットアップ体勢=軸足が投げる状態に入っていること(注意2度で警告1)。
40秒ルール(全文を順序立てて説明できるように)
① 一方の選手が審判に申告し、審判が認めた場合に発動(コントロール責任者及び役員も、著しく遅いと判断した場合に発動できる)。
② 審判はコントロールに発動を報告し、ストップウォッチを受け取る。
③ 両選手に発動(申告した選手にも適用)。
④ 計測 = 一方の選手がダーツを抜いてスローラインを超えてから、もう一方の選手がダーツを抜きスローラインを超えるまで。
⑤ 30秒経過で審判が「10秒前」と伝える。
⑥ 40秒経過 =「40秒ファール」→ そのラウンドの得点・マーク数は無効。
⑦ やむを得ない中断で40秒超過した場合は適用除外が認められる。
⑧ アディショナルコール: 40秒ルール適用後、1レグにつき各選手1回だけ使用可。発動したラウンドに限り40秒の追加時間。使用時は審判に伝える。審判が認識していない場合は無効。審判は相手選手へ伝える。
⚠️ 新規定 — 「アディショナルコール」は近年追加の制度。古い過去問情報には存在しないが、新しい部分ほど出題価値が高い。回数(1レグ各1回)・申告先(審判)・認識なしは無効、を確実に。

Ⅱ-C コイントス — 旧規定から大変更

・コイントスはマシンコイントス機能を使用し、審判が行う。
・コイントスのみの場合、機能により選ばれた選手が先攻・後攻を決める権利を持つ。
・予選ラウンドロビン: 最初のレグ=コイントスのみで先攻・後攻決定 / 最終レグ=コイントスコークで先攻・後攻及びゲームの選択。
・決勝トーナメント: 最初のレグ=コイントスコーク / 最終レグ=コイントスコーク+ゲーム選択。
⚠️ 引っかけ注意 — 旧規定は「PERFECT公式コイン(なければ100円硬貨)」「表裏の優先権はロビン表の上側/マッチカードの左側」だったが、現行はマシンのコイントス機能。ただしクリケット同点時の再コイントスの優先権「直前のコイントスで優先権を持たなかった選手」は現行も生きている(Ⅱ-G)。

Ⅱ-D コーク

・各選手が中心に向かって1本投げ、ブルの中心(センターホール)に近い方が先攻・後攻及びゲームを決める権利を持つ。
・先に投げた選手のダーツは抜かない。ただし先の1本がセンターホールに入った場合、後から投げる選手は抜くことを審判に要求できる。
・ボードに刺さるまで続けて投げる。
・後から投げたダーツで先のダーツが抜けてしまった場合 → やり直し+先攻後攻を入れ替える。
・中心から全く同じビット数 → ダーツは抜かずにやり直し+入れ替え。
・決着がついたら審判はダーツを抜く前に必ず勝敗を伝える。伝える前に抜いた場合、選手の申告でやり直し+入れ替え。
・ダーツを抜く時は自身のダーツのみ抜く。

Ⅱ-E 審判(レフリー)の役割

・予選RR = ラウンドロビン表に記載された順番 / 決勝T = 前試合の敗者(1回戦目はコントロールが決定)。
・敗者は自身に勝利した選手の次の試合が終了するまで、いつでも審判を行える状態で待機。
・「P.TOS」表示の開始時刻を過ぎ、選手2名が揃ってから5分経っても審判が来ない → 選手がコントロールへ申し出 → 呼び出し。さらに5分で審判に警告1。
・審判を放棄・遅延/不在の正当理由を申し出なかった → 即日15,000円の罰金。
・マシントラブル時にスコア未記入 → 審判警告1+当該レグから再試合。
・試合中の問題は選手2名+審判の3名でその場で判断が原則。速やかに中断しコントロールへ。試合終了後の申し出は原則無効。
・フィニッシュ方法・アレンジなどのアドバイス禁止。対戦相手の申告があった場合、審判は警告。
・ゲーム終了後は速やかに両者のスタッツを記入。アウトボードセンサー不反応時は正しい本数で計算して記入。

Ⅱ-F 01ゲーム / Ⅱ-G クリケット

01ゲーム
・ダブル枠=2倍 / トリプル枠=3倍。セパレートブル表記なし=アウター・インナー共50点 / 表記あり=アウター25点・インナー50点。
・マスターアウト(MO): ダブル枠・トリプル枠・ブル(アウター、インナー)でフィニッシュ。
・ダブルアウト(DO): ダブル枠またはインナーブルでフィニッシュ。
・バースト=得点が認められず投げる前の点数が残る: ①残り点数以上の得点 ②シングル枠でフィニッシュ ③MO/DO時に残りを1にした場合。
・01のラウンドはノーリミット。
クリケット
・15〜20の数字とブルが点数。アウター25点/インナー50点。
・3本で占有。以降1本につき加算。相手も3本入れたら双方無効。
・全箇所占有 or 15ラウンド終了時に点数が高い方が勝者。
・15R以内に全占有で同点 → 先にすべての箇所を占有した方が勝者。
・15R終了で同点 → マーク数に関わらずコイントスコーク、センターホールに近い方が勝者。コインの表裏の優先権=直前のコイントスで優先権を持たなかった選手。

Ⅱ-I 警告・失格・品行 — 数字が問われる

・1年間で累積4回警告 → 罰金30,000円。累積8回 → その時点で失格+1年間の出場資格喪失。
・警告は受けた日から1年後まで累積(すべて同時に消えるわけではない)。
・警告対象(8項目): ①審判の義務を守れない ②試合遅れ・審判遅れ・サイン遅れ等の遅延行為 ③プロとして相応しくない言動・行動 ④施設使用料分担金の振込期限 ⑤大会エントリー期限 ⑥素振り・構えのタイミングで1試合中に注意2度 ⑦認識できないダーツの使用 ⑧ラウンドロビン表提出時の誤記載。
・失格(5項目): ①累積8回警告で1年出場停止 ②予選の試合をすべて消化できない ③相応しくない服装とコントロール責任者が判断 ④再三の呼び出しに応じない ⑤許可エリア外での飲酒・喫煙。
・失格時: 予選中→残りは不戦敗。不戦勝選手の勝ちレグ・負けレグは2−0。不戦勝の試合は01スタッツアベレージ算出対象外。決勝T中→その時点で敗退、ポイントは反映されるが賞金は発生しない。
⚠️ 引っかけ注意 — 不戦勝のレグ数は旧規定「1−0」→ 現行「2−0」。罰金額も現行は「30,000円」と明記。

Ⅱ-J / Ⅲ 大会の骨格

・予選ラウンドロビン: 最大6名一組・最小5名一組で全員4試合。勝者が決勝Tへ。
・決勝トーナメント: 最小8名・シングルイリミネーション。組み合わせは抽選。
・ゲーム・レグ数は役員が決め、事前に告知。
・コントロール責任者は大会に出場できない。
・エントリー = プロ会員+施設使用料分担金支払い+PHOENIX IDおよびカード番号提出。締切後キャンセル=「大会当日欠席」扱いで返還なし(締切前は返還)。
・代理人は許可されない → 発覚で本人・代理人共失格+1年以上の出場停止 もしくはプロ資格剥奪。
受付・呼出(5分きざみの階段を正確に)
・受付: 公共交通機関の遅延等で3分の1以上の選手が受付できない → 中止・延期・開始時間の変更をPERFECTコントロールが決定。
・開始5分前にP.TOSで呼び出し通知。
・開始時刻後、選手1名未着: 審判はその場で5分待機 → コントロールに報告 → 場内呼び出し+警告 → さらに5分 → 再呼び出し+警告 → さらに5分 → 失格。
・審判未着も同様に5分待機→呼出+警告→5分→再呼出+警告→5分→予選に限り当該試合は無効とし、審判へ警告・出場停止・追放の罰則。
・場内呼び出しに応じなかった審判が当日中に正当理由を報告しない → 即日15,000円の罰金。
試合中のルール
・試合はP.TOS記載の開始予定時刻を過ぎた時点から進行開始。
・競技スペース=テーブルからマシンまでの空間。選手・審判・役員以外と会話 → アレンジ相談の疑いで警告・出場停止・追放の対象。
・先攻・後攻を間違えた場合: 間違えられた選手が1本目を投げた時点でレグ成立。以降は本来の順番。1本目を投げる前に抗議 → 当該レグ無効+再試合。
・マシン等の設置修正を選手が行った → 警告1。
・マシンを離れる: レグとレグの間のみ+審判に申告。時間は10分まで(審判が計測)。離れた選手は次のレグ負け。10分超過で試合負け。レグ中に離れたらそのレグも負け。離れている間、相手は練習スロー可。
・練習: 試合前に6本(ツー・スロー)。中断時も6本まで。可=マシン変更時・40秒ルール等で審判が報告に行く場合 / 不可=アウトボード反応・誤反応の修正・先攻後攻間違いのマシン操作。
得点記録(現行の大原則)
・得点の判定は刺さり位置を優先して行う。刺さり位置が明確ならそれを正とする。
・刺さっている位置=ティップが接触して刺さり、保持されている状態。
・誤反応は両選手および審判の協議のもと刺さり位置に基づき修正できる。
・1投目/2投目の後、刺さったダーツに触った → それ以降のダーツは無効(明らかな誤反応・無反応で審判が対処する場合を除く)。
・得点にならない: 反応せず落下 / 他のダーツに当たり刺さらず止まった(ぶら下がり) / スロー後に選手が手で動かした・触った。
・刺さり位置を優先する例: 刺さっているダーツに別のダーツが当たって別の場所に反応 / 刺さっていないのに反応 / ティップだけが刺さった場合。
・相手の得点への抗議は即座に審判へ。審議終了まで相手はダーツを抜いてはならない。抜いた後の抗議は一切認められない。
・審判記録は大会当日より2週間保持。スタッツ修正申請はこの期間のみ。
⚠️ 最重要引っかけ — 旧規定は「マシンの反応を優先」だったが、現行は「刺さり位置を優先」で真逆。古い情報で覚えると確実に失点する。

Ⅲ-K〜N 予選ラウンドロビン / 決勝T

・RR表は試合が行われるマシンに設置。自分の名前を確認してサイン → 全員のサインが揃ったら記載順に試合 → 終了後、結果を確認しサイン → 全員揃ったらロビン内1位の選手がコントロールへ提出。
・終了サイン前の相互チェック: 1位は3位の結果、2位は1位の結果、3位は2位の結果を確認後サイン。「結果」=勝ち数・勝ちレグ数と負けレグ数の差・01スタッツアベレージ。
・開始/終了サイン時に5分来ない選手 → コントロール報告 → 場内呼び出し → 警告1。
・欠席者修正: 6名ロビンで1名欠席→5名ロビン化 / 5名ロビンで欠席→不戦敗(不戦勝レグは2−0) / 6名で2名以上→①②の順。
・決勝T出場順位 = 勝ち数 → 勝ちレグ数と負けレグ数の差 → 01スタッツアベレージ。スタッツは1レグと2レグのみで算出(3レグ目は対象外)。小数点第3位以下は切り捨て、第2位まで記載。すべて同じ場合は大会エントリー順。
・提出後の誤記入は変更できない。コントロール判断で全員確認のもと修正する場合、該当選手は警告1。
・記入漏れ → 選手及び審判が失格。RR表の改ざん(悪質) → 3大会以上の出場停止。
・マッチカード(決勝T): コントロール作成。審判は選手本人であることを確認し、練習スロー後審判のコールで開始。終了後選手が確認・サイン。確認後の間違いが修正不可なら誤記入が採用される。

Ⅷ マナーと安全対策(新章・出題可能性大)

・試合前後には必ず「お願いします」「ありがとうございました」のあいさつ。
・審判に対しても敬意を示し、投げやりな態度を取らない。
・試合中は過度な接触を控える。清潔な身だしなみ(過度な香料・体臭・衣服の汚れ→注意・指導)。
・違反4類型: ①挑発的な言動(過度なガッツポーズ・勝ち誇った態度・相手のミスを笑う・意図的に音を立てる・視界に入る・試合後に不満を表明) ②過度に大きな声(他の人の集中を妨げる音量等) ③不必要な見下しの態度 ④試合の進行を妨げる行動。

記述問題① 「40秒ルールについて説明せよ」(出題実績あり)

模範解答(現行規定版・約280字)
一方の選手が審判に申告し、審判が認めた場合に発動する(コントロール責任者及び役員が、プレーが著しく遅いと判断した場合も発動できる)。審判はコントロールに発動を報告し、ストップウォッチを受け取る。ルールは申告した選手を含む両選手に適用される。計測は、一方の選手がダーツを抜いてスローラインを超えてから、もう一方の選手がダーツを抜きスローラインを超えるまでの時間で行い、選手は40秒以内にスローイングを終えなければならない。30秒経過時に審判が「10秒前」と伝え、40秒を経過すると「40秒ファール」となり、そのラウンドの得点・マーク数は無効となる。適用後は1レグにつき各選手1回だけ「アディショナルコール」を使用でき、そのラウンドに限り40秒の追加時間が認められる。
書く順番の骨: ①発動条件 → ②審判の動き(報告・ストップウォッチ) → ③両選手に適用 → ④計測区間 → ⑤30秒で10秒前 → ⑥40秒ファールと効果 → ⑦アディショナルコール。この7点が入れば満点近い。

記述問題② 「決勝トーナメント出場(順位決定)について説明せよ」(出題実績あり)

模範解答(現行規定版・約200字)
決勝トーナメント出場は、予選ラウンドロビンの「勝ち数」「勝ちレグ数と負けレグ数の差」「01スタッツアベレージ」から算出した順位で決定される。01スタッツアベレージは1レグと2レグのみで算出し、3レグ目は対象外とする。数値は小数点第3位以下を切り捨て、小数点第2位まで記載する。上記の条件がすべて同じ場合は、大会エントリー順で上位を決定する。なお、不戦勝の試合は01スタッツアベレージの算出対象外である。
⚠️ 旧規定は「四捨五入」だったが現行は「切り捨て」。ここを書き間違えると記述の心臓部を落とす。

作文(最終問題・小論文)

形式(体験記より): 当日は約5テーマから選択(年度により「指定1題+選択1題」)。分量はA4半分〜記入欄4行程度と少なめ。長文力より「短くまとまった内容」が問われる。

過去の出題テーマ実例:
PERFECTプロになったら何を意識していくか ダーツとマナー PERFECTプロ選手として感じること 生涯スポーツとしてのダーツ 自分にとっての社会貢献 地域におけるダーツ普及促進 ダーツのプロの心構えとそれをどう体現するか 理想とするダーツプロとは ダーツをしていて最も感動したこと
どのテーマでも下のテンプレ(結論→理由→規定に紐づく具体行動→締め)で書ける。「マナー」「心構え」「普及・貢献」の3系統で1本ずつ短い骨子を用意しておけば全テーマをカバーできる。

💡 実戦アドバイス(合格者談): 試験当日の理事長の挨拶・話をよく聞いておくと、小論文にそのまま使える話が聞ける。
構成テンプレート(4段構成)
① 結論 — 意識することを1〜2点、最初に言い切る(例: プロとしての品位ある振る舞いと、ダーツ界の発展への貢献)。
② 理由・自分の背景 — なぜそう考えるか。自分のダーツ歴・きっかけを1〜2文。
③ 規定に紐づけた具体行動 — ここで採点者に刺さる。競技規定の言葉を借りるのがコツ:
　・「試合前後のあいさつ、審判への敬意、相手を尊重するマナー」(Ⅷ マナーと安全対策)
　・「常にプロとして行動し、見本になる」(Ⅵ 義務)
　・「ソフトダーツをスポーツとして普及させ、発展に寄与する」(定款・受験資格)
④ 締め — PERFECTの一員として発展に貢献したい、という宣言で閉じる。
例文(約420字・そのまま使える骨格)

私がPERFECTプロになったら意識していきたいことは二つある。一つはプロとしての品位ある振る舞い、もう一つはソフトダーツの発展に貢献することである。

私はダーツを始めてから、この競技の面白さと奥深さに魅了されてきた。同時に、上位のプロ選手たちの、対戦相手や審判への敬意を欠かさない姿勢に強く憧れてきた。プロとは技術だけでなく、周囲に見本を示す存在だと考えている。

そのため、試合の前後には必ず「お願いします」「ありがとうございました」のあいさつを行い、審判として試合を支える際も、公平で正確な進行に責任を持って取り組みたい。競技規定を正しく理解し遵守することは、対戦相手と大会に関わるすべての人への礼儀だと考える。

また、ソフトダーツをスポーツとして広める活動にも積極的に関わり、ダーツを知らない人にもその魅力を伝えていきたい。PERFECTの一員としての自覚を持ち、常にプロとして行動し、ダーツ界の発展に寄与できる選手になることを誓う。
作文の採点は減点法に近いはず。誤字・規定と矛盾する内容・ネガティブ表現(「賞金を稼ぎたい」だけ等)を避け、規定の語彙(発展・寄与・見本・敬意・スポーツ)を散りばめるのが安全です。字数指定があれば8割以上埋める。

Hitorinku アカウント削除のご案内

本ページでは、Up the Moon合同会社（以下「当社」）が提供するアプリ「Hitorinku / ヒトリンク」のアカウントおよび関連データの削除方法をご案内します。

1. アプリ内から削除する（推奨）

Hitorinku は、アプリ内からいつでもアカウントを完全に削除できます。

経営者（管理者）アカウントの場合

  1. 経営者モードでアプリにサインインします。
  2. 「設定」タブを開き、画面下部までスクロールします。
  3. 「🗑️ アカウント削除」の「アカウントを削除する」をタップします。
  4. 確認ダイアログに従って削除を実行します。

サインイン用アカウント（Apple / Google）・クラウド上の全データ（社員・出勤・現場・有給・会社情報）・参加中の社員のアクセス・端末ローカルデータがすべて削除され、復元できません。

※ アカウント自体は残してデータだけ消去したい場合は、同じ「設定」タブの「⚠️ 全データを削除」をご利用ください。

社員アカウントの場合

  1. 社員モードでアプリを開きます。
  2. 「設定」タブを開き、画面下部までスクロールします。
  3. 「🗑️ アカウント削除」をタップします。
  4. 確認ダイアログに従って削除を実行します。

参加中の会社からの退会・有給申請履歴・サインインアカウント（匿名認証）がすべて削除され、復元できません。

※ アカウントは残して会社との紐付けだけ解除したい場合は、同じ画面の「会社から退会」をご利用ください。

2. メールで削除を依頼する

アプリをすでにアンインストールした場合や、端末を利用できない場合は、メールで削除をご依頼いただけます。

宛先: support@upthemoon.co.jp
件名: 「Hitorinku アカウント削除希望」
本文: ご登録内容の確認のため、①経営者 / 社員の別 ②会社名（経営者の場合）または参加していた会社名（社員の場合）③サインインに使用したアカウントの種類（Apple / Google / 招待コード参加）をお知らせください。

通常2〜3営業日以内にご返信し、ご本人確認のうえ削除を実施します。

3. 削除されるデータと保存期間

  • 削除されるデータ: サインインアカウント・出勤データ・人工データ・社員情報・現場情報・有給データ・招待コード・会社情報
  • クラウド（Supabase）上のデータは、削除実行後 90日以内にバックアップを含め完全に削除されます。
  • 行動分析データ（PostHog・匿名 UUID）は、アカウントとは紐づかない形で最長2年間保持された後、自動削除されます。
  • お問い合わせ履歴は、受信から3年間保持した後に削除されます。

※ 労働基準法に基づく出勤記録の保存義務（5年間・経過措置中は3年間）は雇用主である採用企業に課されるものです。アカウント削除前に必要な記録を CSV / PDF でエクスポートすることをおすすめします。

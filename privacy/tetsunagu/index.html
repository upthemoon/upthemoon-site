第4条（広告・トラッキング）

本サービスは、広告配信および利用者の行動を追跡するトラッキングを行いません。第三者の広告 SDK・行動分析 SDK を組み込んでいません。

そのうえで、障害を早く見つけて直すこと、および通知を届けることのために、必要最小限の情報だけを外部のサービスへ送ります。具体的には、エラー監視のために Sentry へ送る情報と、プッシュ通知の配信のために Apple・Google へ渡す情報です。内容は第3条のとおりです。これらを広告や利用者の行動の分析に使うことはありません。

診断の回数の集計は、個人の行動履歴を作って広告の対象を選ぶために利用しません。診断結果の下に表示する任意の応援協賛への案内は、診断結果に応じて選ぶ広告ではなく、利用・支援の有無は診断結果に影響しません。法人のエールは、送った法人の自発的な操作を法人名付きで示すもので、当社が法人に代わって応援内容を作成したり、送信を依頼したり、送信の対価を受け取ったりするものではありません。

第5条（Cookie 等の利用）

Web 版では、ログイン状態の維持およびリクエスト改ざん防止（CSRF 対策）のために必要な Cookie のみを使用します。これらは本サービスの動作に不可欠なものであり、広告や行動分析の目的では使用しません。ブラウザの設定で Cookie を無効にした場合、ログインを要する機能は利用できません。

第6条（データの保管期間）

主なデータの保管期間は次のとおりです。

アカウント情報・投稿内容は、アカウントが存続する間、または利用者が削除するまで保管します。

法人審査のために提出された資料（任意の補足資料のほか、個別確認の名刺・会社の書類を含みます）は、審査完了後 90 日以内に削除します。会社 URL は企業ページに表示するため、法人アカウントが存続する間保管します。法人番号・会社ドメインメールの認証記録は、認証状態の維持のため、法人アカウントが存続する間保管します。

審査の結果が出ないまま 180 日が過ぎた申請は、取り下げたものとして扱い、提出された資料は取り下げ扱いの日から 90 日以内に削除します。

資料のアップロードの手続を始めたものの、申請に登録されなかったファイルは、発行から 24 時間で削除します。

認証コード（OTP）は発行から 10 分で失効します。失効または使用済みとなった記録は、不正利用の検知のために 3 日間だけ残し、その後に削除します。

ログインのセッションの記録は、有効期限が切れてから 7 日後に削除します。

二重送信を防ぐための記録は、作成から 24 時間で削除します。

企業ページの閲覧・クリックの集計用の記録（第2条の符号と日付）は、記録した日の翌日の終わりまで保管し、それより古い日付の記録は毎日の処理で削除します。集計後の日ごとの件数は、個人を特定できない数字として残ります。

回数制限のための記録（送信元 IP アドレス・メールアドレス・利用者 ID と、操作の種類・時刻）は、作成から 2 日を過ぎたものを、毎日の処理で削除します。

お問い合わせの記録（内容・連絡先・送信元 IP アドレス）は、対応を終えてから 3 年間保管し、その後に削除します。お問い合わせの本文に氏名・電話番号・メールアドレスなどが書かれていた場合も、その部分は本文と同じ期間保管し、本文とあわせて削除します。退会した方のお問い合わせも同じです。

通報および運営による対応記録は、同種の問題への対応・再発防止のために必要な期間保管します。

契約・決済に関する記録は、法令で定められた帳簿保存期間にわたり保管します。

バックアップには、上記の削除が反映されるまでに時間がかかる場合があります。

アカウントを削除したとき

利用者は、本サービス内の「アカウント削除」により、自身のアカウントおよび当社サーバー上の関連データの削除を請求できます。削除の操作をすると、次のように取り扱います。なお、法人の最後の管理者の方は、先に後任の方を管理者にしていただくまで、削除できません。

消去または匿名化するものは、メールアドレス（再び特定できない形に置き換え、同じアドレスで登録し直せるようにします）、ニックネーム・自己紹介・顔写真、回答者として公開していた氏名・役職、すべての端末のログイン、通知用の端末トークン、ご本人のメールアドレス宛ての認証コードの記録、ご本人のメールアドレス宛ての法人への招待に残っているメールアドレス、お問い合わせの連絡先として記録された氏名・電話番号・メールアドレス、二重送信防止の記録です。まだ公開されていない質問と回答（承認待ちのものを含みます）は削除します。公開済みの質問の投稿者名は「削除済みユーザー」に置き換えます。審査の結果が出ていない法人申請は取り下げ扱いとし、提出された資料は 90 日以内に削除します。

残すものは、公開済みの質問・回答の本文（投稿者との紐付けを解除したうえで、他の利用者の閲覧の継続性のために掲載を続ける場合があります）、法人における所属の変更の記録（所属は終了します）、お問い合わせの本文と送信元 IP アドレス（受付の記録として、対応を終えてから 3 年間保管し、その後に削除します。本文の中に書かれた氏名などは退会時には消さず、この期間が過ぎるまで残ります）、通報・運営による対応記録、法令に基づく契約・決済の記録、運営の操作記録（氏名・メールアドレスは含みません）です。投稿自体の削除を希望する場合は、第8条の窓口へ削除申請を行ってください。

追加機能の記録

新しい機能に関する記録は、表示や取引の確認、不正利用への対応、操作や復元の検証のため、種類ごとに定めた期間保管します。担当者の識別子、申出の理由、同意・撤回の記録などを含む場合があります。退会により公開プロフィールが消去される場合も、法令に基づく保存や、紛争対応・監査等に必要な記録が残ることがあります。記録の保存が必要かどうかと、画面に表示する期間は別に判断します。開示・削除等の申出は第8条の窓口で受け付け、法令に従って確認します。

規約への同意の記録は、その同意が適用されている間保管し、同意の撤回または適用の終了から3年を過ぎた記録を削除・匿名化します。法令上別の保存義務がある記録や紛争対応のために保全が必要な記録は、その対象と必要性を区別して取り扱います。

会社の種類のタグ・エールの操作記録と、回答方式に関する申出・変更の履歴は、その機能の利用の終了から3年を過ぎた記録を削除・匿名化します。履歴の行を消さずに保全する必要がある場合は、担当者などを識別する情報を匿名化します。

個人との対応関係を排除した確定月ごとの統計は、確定から3年間保管し、その期間を過ぎた記録を削除します。

基盤のアクセス記録とバックアップは、基盤の設定に従い一定期間保管します。バックアップには、本体の記録の削除・匿名化が反映されるまでに時間がかかる場合があります。
